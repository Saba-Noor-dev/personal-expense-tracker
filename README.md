# Personal Expense Tracker

A beginner-level Python project that helps users manage their personal expenses and monthly budget through a simple menu-driven interface.

## Features

- Add new expenses with categories.
- View all recorded expenses.
- Edit existing expenses.
- Delete expenses.
- Set a monthly budget.
- View total expenses and remaining budget.
- Get a warning when expenses exceed the budget.
- Basic input validation and error handling.

## Technologies Used

- Python
- Lists and Dictionaries
- Functions
- Loops and Conditional Statements
- Exception Handling

## How to Run

1. Clone or download this repository.
2. Make sure Python is installed.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python main.py
```

## Project Purpose

This project was created to practice Python programming fundamentals and apply them in a practical application.
